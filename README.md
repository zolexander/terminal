# Terminal Environment

## Ziel

Ein einheitliches Terminal-Framework für Debian/KDE.

Jede Konfigurationsdatei muss einen klaren Zweck haben.

Zum Beispiel:

aliases.zsh

Nur Aliases.

Keine Exports.

Keine Funktionen.

Keine Plugins.

## Komponenten

- Zsh
- Starship
- eza
- bat
- ripgrep
- fd
- zoxide
- btop
- fastfetch
