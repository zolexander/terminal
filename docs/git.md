# Git-Modul

## Zweck

Zeigt den aktuellen Branch und den Status des Repositories.

## Farbe

| Farbe | Bedeutung    | Verwendung |
| ----- | ------------ | ---------- |
| Grün  | Erfolg       | Git        |
| Blau  | Identität    | Username   |
| Gelb  | Orientierung | Directory  |
| Rot   | Fehler       | Exit-Code  |
| Cyan  | Interaktion  | Prompt     |


## Symbol

│

## Sichtbarkeit

Nur innerhalb eines Git-Repositories.

## Abhängigkeit

Git muss installiert sein.
